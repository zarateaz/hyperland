## Instalacion 
```bash
- git clone https://github.com/zarateaz/hyperland-kalilinux.git
- cd hyperland-kalilinux
- chmod +x install.sh
- ./install.sh
```

> Ejecuta el instalador como usuario normal (no root). Usa `apt` con los repos de Kali;
> lo que no está empaquetado (wallust, swww, pyprland, waypaper, pokemon-colorscripts,
> JetBrains Mono Nerd Font, zsh-sudo) se instala automáticamente con cargo, pipx o desde el código fuente.
> Al terminar, cierra sesión y elige **Hyprland** en LightDM.
